# Cereza 3D model, headset version

A furnished 3D model of the new house at 784 Cereza Drive, Palo Alto (Tektive Design, design-development set IR2, 27 July 2026), with an immersive VR mode for Meta Quest.

**Open it:** https://dazhichen.github.io/cereza-vr/ in the Meta Quest Browser, then tap **VR**. On a computer the same page shows the plan, the 3D model and the eye-level walk.

**In VR** (walking works as in the La Calle model):
- Walk with either stick, or hold a trigger (or pinch) to walk where you look; hold a grip as well to go faster
- Push the right stick left or right to turn 30 degrees
- Point, then tap a trigger, to jump to a floor, stair or the ground
- B or Y changes floors; A or X goes back to the street

The page is a single self-contained file (`index.html`); it loads three.js r128 from cdnjs and its fonts from Google Fonts.
